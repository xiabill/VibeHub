VibeHub - macOS 状态栏小工具

把 AirPods / 蓝牙耳机的媒体键手势 + 2.4G 遥控键盘的物理按键
统一映射到任意 macOS 键盘 chord。

═══════════════════════════════════════════════════════════
首次启动
═══════════════════════════════════════════════════════════

1. 把 VibeHub.app 拖到「应用程序」文件夹
2. 打开会被 macOS 拦下（self-signed app）：
   系统设置 → 隐私与安全性 → 拉到最下 → 「仍要打开」
3. 授权两个权限：
   • 辅助功能       — AirPods 模块 + Remote 模块都需要
   • 输入监听       — Remote 模块读 HID 设备需要
   在「系统设置 → 隐私与安全性」里分别打开 VibeHub
4. 杀掉 app 重启一次：
     pkill -f VibeHub && open /Applications/VibeHub.app
5. 状态栏出现 ⌘ 图标 = 成功

═══════════════════════════════════════════════════════════
使用
═══════════════════════════════════════════════════════════

• 左键状态栏图标 → 打开配置面板（AirPods / Remote 两个 Tab）
• 右键状态栏图标 → 快捷菜单（启停、权限、退出等）

AirPods Tab：
  - 单击 / 双击 / 三击 / 音量+ / 音量- 五种手势独立配置
  - 每个手势可挂 1 到 N 个按键（chord）
  - 「点按」立即触发；「按住」按一下进入按住状态、再按一下释放
  - 默认：单击 = 按住 Left Option（Typeless / WhisperKey 友好）

Remote Tab：
  - 默认匹配 XING WEI 0x1915:0x1025；可在「目标设备 → 切换…」选其他 HID 键盘
  - 12 颗按键全部可独立映射（方向键 / OK / 菜单 / 主页 / 返回 / 语音 / 静音 / 音量±）
  - 长按自动重复（启动延迟 + 重复间隔可调）

═══════════════════════════════════════════════════════════
兼容性
═══════════════════════════════════════════════════════════

✅ 工作：
  • AirPods 1/2/3/4（普通版）和 AirPods Max
  • 任何走 AVRCP 协议的蓝牙耳机的 Play/Pause + 音量+/-（部分双击）
  • XING WEI 等常见 2.4G USB 遥控键盘

❌ 不工作：
  • AirPods Pro 2 / Pro 3（stem 事件走 MediaRemote 私有 IPC）
  • 蓝牙连接的遥控器（要改代码切换到 IOBluetooth）

完整说明见 README.md 或项目主页 https://github.com/xiabill/VibeHub
